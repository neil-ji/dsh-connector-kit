安装

通过 npm 安装（推荐，发布产物无需 build 授权）：

dsh plugin --profile <name> add dsh-connector-github

或从源码构建安装：

git clone https://github.com/neil-ji/dsh-connector-kit.git
cd dsh-connector-kit && pnpm install && pnpm build
dsh plugin --profile <name> add file:./packages/dsh-github
首次安装后在 Web 设置页（设置 → GitHub 连接）粘贴 GitHub Personal Access Token，即可开始使用全部工具。

npm 一键发布管线

一个想法 → 打 tag 全自动发布；人工只出现在绕不开的 2FA 环节

1
npm_launch（stage: launch）

校验包名 → 生成可发布 TS 包（含 OIDC release 工作流 + Pages 站点）→ 建仓 → 推初始提交 → 开 Pages

2
人工跑 2FA 脚本（一次性）

首次 npm publish + npm trust（浏览器 2FA，Agent 无法代跑）

3
npm_launch（stage: tag）

创建 v<next> tag，CI 经 OIDC trusted publishing 免 2FA 全自动发布
