给 DeepSeek Harness 接入 GitHub + npm 自动化

第三方 DSH 连接器套件（不改 dsh 源码）：40 个 GitHub Agent 工具覆盖建仓/推送/PR/审查/Actions/Pages 全链路， 外加 npm 一键发布管线（scaffold → 建仓 → OIDC release → Pages）与 Web 设置页。

开始安装 阅读官方文档

核心能力

围绕发布工作流设计：建仓 → 写代码 → 提交 → 推送 → PR → 审查 → 发版

仓库 & 身份

  • 创建 / 读取 / 编辑仓库元数据
  • 用户仓库列表、仓库搜索、fork
  • whoami 显示 token scopes

git 操作

  • github_push：add/commit/push（永不 force）
  • github_pull / github_clone
  • token 走内联 credential helper，不进仓库配置

内容与提交

  • 读文件 / 目录、整棵文件树、README
  • Contents API 单文件提交
  • 提交列表与单个提交的变更 patch

PR & 审查

  • 创建 / 列表 / 读取 PR
  • 提交 review（approve / request changes）
  • PR 变更文件 + 评论

Issue / Release / Pages / Actions

  • Issue 全流程 + 评论（PR 通用）
  • Release 创建（支持 draft）
  • 工作流查询 / 触发 / artifacts，Pages 状态与构建

Web 设置页

  • token 凭证写入（只写不回读）
  • git 身份、默认可见性、权限开关
  • gitProxy 代理配置 + 健康检查

安装

通过 npm 安装（推荐）：

dsh plugin --profile <name> add dsh-connector-github

或从源码构建安装：

git clone https://github.com/neil-ji/dsh-connector-kit.git
cd dsh-connector-kit && pnpm install && pnpm build
dsh plugin --profile <name> add file:./packages/dsh-github
首次安装后在 Web 设置页（设置 → GitHub 连接）粘贴 GitHub Personal Access Token，即可开始使用全部工具。
